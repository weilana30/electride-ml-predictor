# GNN poster figures

Generated by `make_figures.py` from the feature-study frozen final-test
predictions and the committed architecture-test `run_metrics.csv`. All numbers
are on the family-held-out test split (5,000 structures, 88,680 voids, 9
named-phase families) and are mean ± SD over three seeds unless noted.

| Figure | Shows |
| --- | --- |
| `gnn_parity_atom_only.{png,pdf}` | DFT vs predicted ELF at void centers for the atom-only heterogeneous GNN (median-RMSE seed) |
| `gnn_model_comparison.{png,pdf}` | Test RMSE of every model family against predicting the average ELF |

## Numbers

| Model | Test RMSE |
| --- | ---: |
| **Hetero GNN, atom-only (width 64; feature study)** | **0.058 ± 0.002** |
| Hetero GNN, all descriptors (width 128; architecture test) | 0.065 ± 0.001 |
| Gated MPNN | 0.070 ± 0.003 |
| Gradient-boosted tree (1 run) | 0.077 |
| Fixed-context MLP | 0.085 ± 0.002 |
| Void-only MLP | 0.140 ± 0.000 |
| Predict the average ELF | 0.141 |

Atom-only GNN: R² 0.83 ± 0.01, MAE 0.038 ± 0.001.

- The void-only MLP is no better than predicting the average: a void's ELF
  depends on its surrounding atoms.
- High-ELF voids are under-predicted. Of test voids with DFT ELF ≥ 0.5,
  the atom-only model predicts ≥ 0.5 for 63% (precision 0.83). Of the rare
  voids with ELF ≥ 0.7 (0.7% of test voids), it catches only 6%. The
  strongly localized voids that matter most for electrides are the weakest
  part of the model.
- The two highlighted GNNs come from different studies (feature study at
  width 64, architecture test at width 128) on the same split and protocol.
  The confirmation study comparing them directly is still in progress.
- "Predict the average" uses the test-set mean, which is slightly optimistic
  for a constant predictor.
