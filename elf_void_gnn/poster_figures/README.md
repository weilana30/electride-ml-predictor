# GNN poster figures

Generated by `make_figures.py` from the feature-study frozen final-test
predictions and the committed architecture-test and confirmation-study metrics.
The parity plot uses the feature study; the two GNN bars use the later direct
confirmation study. All use the same family-held-out test split (5,000
structures, 88,680 voids, 9 named-phase families).

| Figure | Shows |
| --- | --- |
| `gnn_parity_atom_only.{png,pdf}` | DFT vs predicted ELF at void centers for the atomic-features atom–void GNN; density is the median-RMSE seed and metrics are feature-study mean ± SD over 3 seeds |
| `gnn_model_comparison.{png,pdf}` | Four selected approaches; GNNs are direct confirmation values and MLPs are earlier architecture-study values |

Atom-only GNN: R² 0.83 ± 0.01, MAE 0.038 ± 0.001.

- The void-only MLP is no better than predicting the average: a void's ELF
  depends on its surrounding atoms.
- High-ELF voids are under-predicted. Of test voids with DFT ELF ≥ 0.5,
  the atom-only model predicts ≥ 0.5 for 63% (precision 0.83). Of the rare
  voids with ELF ≥ 0.7 (0.7% of test voids), it catches only 6%. The
  strongly localized voids that matter most for electrides are the weakest
  part of the model.
- “Atomic features” means explicit void descriptors are zeroed; void nodes and
  atom–void messaging remain in the model.
- The chart's two GNN values are from the direct confirmation study. The
  parity panel shows the earlier feature study, so its 0.058 ± 0.002 differs
  slightly from the confirmation value of 0.059 ± 0.003.
- MLP comparison values come from earlier architecture runs on the same test
  split; they are context, not a controlled comparison against the GNNs.
- "Predict the average" uses the test-set mean, which is slightly optimistic
  for a constant predictor.
